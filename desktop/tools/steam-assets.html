Frontier's End — Steam görselleri

Steam simgeleri build/icon.png çiziminden küçültülür; başarım simgeleri (kazanılmış + kilitli) oyunun kendi glif setinden üretilir. Hepsini dosyalara yazmak için: cd desktop && npm run steam-assets. Steamworks başarım simgeleri 64×64 JPG ister; simge boyutu aşağıdan değiştirilebilir.
